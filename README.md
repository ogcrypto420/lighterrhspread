# Lighter RH — алерты по спреду и стакану акций

Telegram-бот следит за всеми парами **акций** на Lighter (Robinhood Chain) и пишет, когда у пары
одновременно узкий спред и плотный стакан — то есть можно зайти без размытия цены.

## Что именно проверяется

Пара считается «актуальной», когда **все** условия держатся `HOLD_SECONDS` секунд подряд:

| Фильтр | Что значит | По умолчанию |
|---|---|---|
| `spread` | (ask − bid) / mid | ≤ 0.003% |
| `impact` | насколько средняя цена рыночной заявки на `size` $ уедет от лучшей цены (отдельно buy и sell, берётся худшее) | ≤ 0.005% на $5000 |
| `depth` | сколько $ стоит в полосе ±`band`% от середины, на каждой стороне | ≥ $20 000 в ±0.02% |

`impact` — главный показатель «плотности»: он отвечает прямо на вопрос «если я зайду на свой размер, сколько я потеряю сверх спреда».
Поставь `ORDER_SIZE_USD` равным своему реальному размеру входа.

**Важно про 0.003%.** Минимальный шаг цены у большинства акций — $0.01. Для акции за $218 (NVDA) один тик — это уже 0.0046%,
то есть спред 0.003% там физически невозможен. При запуске бот пишет, какие пары по текущему порогу не пройдут никогда.
Если хочешь ловить и их — подними порог (`/set spread 0.005`).

## Запуск

1. В Telegram открой **@BotFather** → `/newbot` → получи токен.
2. Установи Python 3.10+ и зависимость:
   ```
   pip install -r requirements.txt
   ```
3. Скопируй `.env.example` в `.env` и впиши `TG_TOKEN`.
4. Запусти: `python bot.py`
5. Напиши своему боту `/start` — он ответит твоим **chat id**. Впиши его в `TG_CHAT_ID` в `.env` и перезапусти.

## Работа 24/7 через GitHub + Railway (без своего сервера)

Railway сам берёт код из GitHub-репозитория, держит бота запущенным круглосуточно, перезапускает при падении
и обновляется при каждом пуше в репозиторий. Стоит около $5 в месяц.

1. Зайди на [railway.com](https://railway.com) через GitHub.
2. **New Project → Deploy from GitHub repo** → выбери этот репозиторий. Railway найдёт `Dockerfile` сам.
3. Открой сервис → вкладка **Variables** → добавь `TG_TOKEN` и `TG_CHAT_ID`. Остальные пороги по желанию,
   имена такие же, как в `.env.example`.
4. Сервис перезапустится, и бот пришлёт в Telegram «🚀 Мониторинг запущен».

`.env` в репозиторий не кладётся (он в `.gitignore`): токен хранится только в Variables на Railway.
Пороги, изменённые через `/set`, сбрасываются к значениям из Variables при каждом новом деплое.
Если хочешь, чтобы изменения сохранялись навсегда, впиши их в Variables.

## Свой сервер (VPS)

Пример для Linux (systemd), файл `/etc/systemd/system/lighter-bot.service`:
```
[Unit]
Description=Lighter RH spread bot
After=network-online.target

[Service]
WorkingDirectory=/opt/lighter_bot
ExecStart=/usr/bin/python3 /opt/lighter_bot/bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```
Затем `sudo systemctl enable --now lighter-bot` и логи — `journalctl -u lighter-bot -f`.

## Команды в Telegram

- `/status` — топ-15 пар по спреду прямо сейчас (✅ — проходит все фильтры), `/status 30` — топ-30
- `/settings` — текущие пороги
- `/set spread 0.005` · `/set size 10000` · `/set impact 0.01` · `/set depth 50000` · `/set band 0.05` · `/set hold 10` · `/set cooldown 30` · `/set notify_lost off`
- `/pause`, `/resume` — выключить/включить алерты
- `/pairs` — какие пары в мониторинге

Изменения через `/set` сохраняются в `settings.json` и переживают перезапуск (приоритетнее `.env`; удали файл, чтобы вернуться к `.env`).

## Как бот отличает акции

В API Lighter нет поля «класс актива». Бот использует признак из параметров рынка: у крипто-перпов базовая ставка
фандинга 0.0100, у RWA — 0.0032. Среди RWA вручную выделены ETF (SPY, QQQ, SOXL, USO, SLV, SGOV), сырьё (XAU, XAG)
и pre-IPO (OPENAI, ANTHROPIC, SHEIN). Всё остальное — акции. По умолчанию в мониторинге акции и pre-IPO,
ETF и сырьё включаются флагами `INCLUDE_ETF` и `INCLUDE_COMMODITIES`. Новые листинги подхватываются автоматически
(список рынков обновляется раз в 10 минут, бот пишет «🆕 Новые пары»). Если что-то определилось неверно —
поправь через `EXTRA_STOCKS` / `EXTRA_ETF` / `EXTRA_PREIPO` / `EXTRA_CRYPTO` / `EXCLUDE` в `.env`.

## Технически

- Данные публичные, ключи Lighter не нужны. REST: `https://api.rh.lighter.xyz`, стаканы — WebSocket `wss://api.rh.lighter.xyz/stream`
  (режим `readonly=true`, работает и из регионов с ограничениями).
- Стакан собирается из снапшота и дельт, целостность проверяется по `nonce`; при пропуске бот сам переподписывается,
  при обрыве — переподключается.
- REST дергается раз в 10 минут, так что лимит 60 запросов/мин не задевается.
